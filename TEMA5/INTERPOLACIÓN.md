## Interpolación
#### La interpolación es un método matemático que se utiliza para estimar valores desconocidos a partir de datos conocidos. Consiste en calcular un valor que se encuentra dentro de un intervalo de puntos ya establecidos. Por ejemplo, si se conocen ciertos valores de una tabla o una gráfica, la interpolación permite aproximar los valores intermedios entre esos datos. Este método es muy utilizado en áreas como ingeniería, física, programación, estadística y análisis de datos, ya que ayuda a obtener resultados aproximados cuando no se tiene la información completa. La interpolación puede realizarse de diferentes formas, como la interpolación lineal, polinómica o mediante splines, dependiendo de la precisión que se necesite y del tipo de datos con los que se trabaje.
